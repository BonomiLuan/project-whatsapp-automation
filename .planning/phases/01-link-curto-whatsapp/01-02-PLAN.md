    Imports:
    - import { Pool } from 'pg'
    - import { randomBytes } from 'crypto'

    Pool configuration:
    - connectionString: process.env.DATABASE_URL
    - max: 10
    - idleTimeoutMillis: 30_000
    - connectionTimeoutMillis: 5_000

    Register: process.on('SIGTERM', () => pool.end())

    ALPHABET constant: 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789'

    generateCode(): uses randomBytes(4), loops 5 iterations using bytes[i % 4] % ALPHABET.length as index. Returns 5-char string.

    generateUniqueCode(): loops up to 10 attempts. Each attempt: call generateCode(), query 'SELECT 1 FROM links WHERE code = $1' with [code], return code if rows.length === 0. After 10 failures throw Error('Could not generate unique code after 10 attempts').

    ALLOWED_IMAGE_HOSTS array of 5 RegExp: /\.shopee\.com\.br$/, /\.szcdn\.com$/, /\.ssl-images-amazon\.com$/, /\.cloudfront\.net$/, /\.mlstatic\.com$/

    isSsrfAllowed(imageUrl: string): boolean — wraps new URL(imageUrl) in try/catch (returns false on throw), tests hostname against ALLOWED_IMAGE_HOSTS regexes.

    ALLOWED_AFFILIATE_PREFIXES string array: ['https://shopee.com.br', 'https://www.shopee.com.br', 'https://s.shopee.com.br', 'https://amazon.com.br', 'https://www.amazon.com.br', 'https://amzn.to', 'https://www.mercadolivre.com.br', 'https://mercadolivre.com.br', 'https://www.mercadolibre.com', 'https://meli.la', 'https://ml.bz']

    initLinksTable(): runs the CREATE TABLE IF NOT EXISTS SQL from D-01 schema exactly as specified, plus CREATE INDEX IF NOT EXISTS idx_links_code.

    createLink(data): validates affiliate_url starts with one of ALLOWED_AFFILIATE_PREFIXES (throws Error('Invalid affiliate URL domain') if not), generates unique code, inserts with expires_at = NOW() + INTERVAL '45 days', returns rows[0].

    getLink(code: string): SELECT * FROM links WHERE code = $1; returns rows[0] ?? null.

    incrementClick(code: string): UPDATE links SET click_count = click_count + 1 WHERE code = $1. Errors are swallowed silently (use try/catch returning void).

    getLinks(limit = 100): SELECT * FROM links ORDER BY created_at DESC LIMIT $1; returns rows.

    buildExpiredRedirectUrl(source, title):

| /r/:code → getLink() | URL path parameter crosses into SQL query |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02 | Tampering | SQL queries in pool.query() | mitigate | All queries use parameterized form ($1, $2...) — per D-04. No string concatenation with user-controlled values |
| T-01-03 | Elevation of Privilege | isSsrfAllowed() in /img/:code | mitigate | ALLOWED_IMAGE_HOSTS regex allowlist on hostname — per D-04. new URL() parse prevents auth@ and port bypass |
