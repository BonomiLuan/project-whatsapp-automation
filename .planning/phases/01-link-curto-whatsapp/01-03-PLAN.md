<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WhatsApp crawler → GET /r/:code | Public URL, unauthenticated — OG tag HTML must be safe to return |
| WhatsApp crawler → GET /img/:code | Public URL — fetches image from our domain to bypass CDN auth |
| /img/:code → upstream CDN | Outbound HTTP using image_url from DB |
| end user browser → /r/:code | Rate-limited; meta refresh sends to affiliate URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Elevation of Privilege | /img/:code SSRF | mitigate | isSsrfAllowed() from links.ts enforces 5-domain hostname allowlist (per D-04). Called before axios.get |
| T-01-07 | Spoofing | og:image absolute URL | mitigate | getBaseUrl() uses x-forwarded-proto header for Railway HTTPS detection. BASE_URL env var as fallback |
| T-01-08 | Tampering | click_count inflation | mitigate | redirectLimiter: 60 req/min/IP via express-rate-limit v8 (per D-04) |
| T-01-09 | Spoofing | Open redirect via expired link | accept | buildExpiredRedirectUrl only returns hardcoded platform URLs (shopee, amazon, ML) — source comes from DB, not user input |
| T-01-10 | Info Disclosure | /api/links data exposure | mitigate | Protected by existing app.use('/api', isAuthenticated) middleware at line 52. No whitelist entry for /links needed |
| T-01-11 | Info Disclosure | /r/:code exposes link metadata in HTML | accept | og:title and og:description are intentionally public (link is shared). affiliate_url in meta refresh is the affiliate URL the user already received |
| T-01-SC | Tampering | npm installs | accept | No new npm installs in this plan; rateLimit and pg already installed per package.json |
</threat_model>
